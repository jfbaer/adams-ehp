# Released dataset (as cited in the preprint)

These are the data files named in the Data statements of the
[preprint](../paper/lambda.pdf), under the names the paper uses. Each is a
copy of the corresponding pipeline file in
[`python/data/E2/`](../python/data/E2/), which remains the source of truth
consumed by the propagator:

| File here | Pipeline file | Contents |
|---|---|---|
| `rank.csv` | `E2_rank.csv` | dimension of H^{s,f}Λ(n) at each tridegree `(n, s, f)`, including the n=0 Λ(C2) column |
| `names.json` | `E2_names.json` | basis class → lexicographically leading admissible monomial of a cycle representative |
| `compositions.csv` | `E2_relations.csv` | all algebraic compositions (the multiplication table) |
| `E.csv`, `H.csv`, `P.csv` | `E2_E.csv`, `E2_H.csv`, `E2_P.csv` | the algebraic EHP maps |
| `C2.csv` | `E2_C2.csv` | Mahowald's map to Λ(C2) |

All tables are complete through total degree s + f ≤ 76 (some extend
partially beyond, from banded generation runs; entries there are correct but
not exhaustive). The full cycle representatives and Curtis tags are not
shipped — they are regenerated by the Rust implementation (see
[`rust/README.md`](../rust/README.md)); the CSV formats are documented in
[`rust/README.md`](../rust/README.md) and `rust/src/io/csv.rs`.
